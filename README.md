### SYSTEMBANK
Integrated banking system in Python using OOP concepts without any framework.
An educational banking system developed using object-oriented programming (OOP) in Python without any framework.

The project aims to simulate a real banking system while applying the basic concepts of OOP by separating tasks into layers (data, logic, and UI).

###  Key Features:
- **Customer Management:**
- Show Client List
- Add New Client
- Update Client Info
- Delete Client
- Find Client

- **Bank Transactions:**
- Withdrawals, deposits, and transfers between accounts
- View transaction history

- **Manage Users & Permissions:**
- Create new users
- Set login permissions (Admin/User)
- Login and logout

- **Currency Exchange:**
- Display currency rates
- Convert amounts between currencies using custom data files

- **Data Storage:**
- Use `.JSON` and `.TXT` files to store customer, user, and transaction data
- Organize the data layer separately from the logic and interface

- **Interactive and organized CLI:**
- Clear and easy-to-use menus
- Clean Screen transitions for an elegant interface.
- Smart and understandable error handling.
